# 🍔 Delícias Santana

API REST desenvolvida com Java, Spring Boot e MySQL para gerenciamento de um restaurante.

## 🚀 Funcionalidades

- CRUD de clientes
- CRUD de mesas
- CRUD de cardápio
- CRUD de pedidos
- Relacionamento entre entidades com JPA
- Validação de dados
- Spring Security
- API REST

## 🛠 Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Maven
